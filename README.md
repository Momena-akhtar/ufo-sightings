# The Night the Sky Got Weird

It began with a single message in a sleepy town: lights and shapes over the ridge, hovering, then gone.

By midnight, the calls were everywhere - a farmer with binoculars, a teenager recording on a phone, an astronomer noting an impossible reflection. The reports were messy, human and beautiful: stamps on the margin of ordinary nights, the raw witness marks we keep in `data/raw/`.

This repo is a small reconstruction: `data/processed/` holds stitched timelines, `scenes/` replays moments, and `assets/` provides sounds and images.

To experience: run the default scene or list scenes with:

```bash
python3 main.py
```

Please keep witness notes and provenance intact.
